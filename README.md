# Desenvolvimento de Contratos - Maeoka Engenharia

Repositorio de desenvolvimento dos documentos contratuais da Maeoka Engenharia.

## Documentos

Este repositorio contem **dois documentos que devem ser mantidos em conjunto**:

### 1. Clausulas Contratuais do Cliente
**Arquivo:** `clausulas-contratuais-maeoka.html` (+ versao `.docx`)

Contrato assinado pelo **cliente (contratante)**. Contem todas as clausulas que regem a relacao entre o cliente e a Maeoka Engenharia: objeto, pagamento, prazos, garantias, responsabilidades, etc.

### 2. Manual de Contratacao de Subempreiteiros
**Arquivo:** `manual-contratacao-subempreiteiros.html`

Manual assinado pelos **subempreiteiros/prestadores de servico (MEIs)**. Explica como funciona trabalhar com a Maeoka: contratacao, inspecao, pagamentos, retencao tecnica, materiais, obrigacoes e rescisao.

## Regra importante

Esses dois documentos se complementam. Ao alterar um, **verifique se o outro precisa ser atualizado** para manter a coerencia. Exemplos:

- Se alterar o fluxo de aprovacao no contrato do cliente, atualizar tambem no manual do subempreiteiro
- Se alterar prazos de garantia, ambos devem refletir os mesmos prazos
- Se alterar regras de medicao/pagamento, verificar se os dois documentos estao alinhados
